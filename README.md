# 🍔 FastAPI Food Delivery Backend

## 📌 Project Overview

This project is a Food Delivery Backend System built using FastAPI.

It demonstrates:
- REST API development
- CRUD operations
- Search, sorting, and pagination
- Cart and checkout workflow
- Pydantic validation
- Swagger API testing


## 🛠️ Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
