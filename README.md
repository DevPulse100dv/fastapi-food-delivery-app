# 🍔 FastAPI Food Delivery Backend

## 📌 Project Overview

This project is a Food Delivery Backend System built using FastAPI.

It demonstrates:
- REST API development
- CRUD operations
- Search, sorting, and pagination
- Cart and checkout workflow
- Pydantic validation
- Swagger API testing

---

## 🚀 Features

✅ GET APIs  
✅ POST APIs  
✅ PUT APIs  
✅ DELETE APIs  
✅ Pydantic Validation  
✅ Helper Functions  
✅ Search APIs  
✅ Sorting APIs  
✅ Pagination APIs  
✅ Cart Workflow  
✅ Checkout System
